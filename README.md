# حارس البرج — بناء ملف APK للأندرويد

## الخطوات (بدون تثبيت أي برنامج)

1. أنشئ حساباً مجانياً في github.com إن لم يكن لديك.
2. أنشئ مستودعاً جديداً (New repository)، وسمّه مثلاً tower-guard.
3. ارفع كل محتويات هذا المجلد إليه (Add file ← Upload files).
   مهم: تأكد من رفع المجلد المخفي `.github` أيضاً. إن لم يظهر في جهازك
   فعّل خيار "إظهار الملفات المخفية"، أو استخدم GitHub Desktop.
4. افتح تبويب Actions في المستودع، واختر Build APK ثم Run workflow
   (يبدأ تلقائياً أيضاً عند الرفع). انتظر 5 إلى 10 دقائق.
5. ادخل على عملية البناء الناجحة (علامة صح خضراء)، ونزّل من الأسفل
   ملف tower-guard-apk. فك ضغطه لتجد app-debug.apk.
6. انقل الملف لهاتفك وافتحه. إن طلب الهاتف، اسمح بالتثبيت من هذا المصدر.

## لتحديث اللعبة
استبدل الملف www/index.html بنسخة اللعبة الجديدة وارفعه، فيُبنى APK جديد.

## ملاحظات
- هذا APK تجريبي (debug) مناسب للتثبيت المباشر ومشاركته مع الأصدقاء.
- للنشر في Google Play تحتاج نسخة AAB موقَّعة وحساب مطوّر.
- تقدم اللاعب محفوظ داخل التطبيق، لكن إعادة التثبيت بتوقيع مختلف قد تمسحه.
